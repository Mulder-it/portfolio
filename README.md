# portfolio
Personal portfolio website built with Django Ninja, PostgreSQL , React and Docker

Personal showcase website presenting my project, skills and background.

This project is also a learning ground: I am building it as a real
professional project, from UX/UI analysis all the way to deployment.

## Tech stack

- **Backend**: Python, Django, Django Ninja
- **Database**: PostgreSQL
- **Frontend**: React, Vite
- **Infrastructure**: Docker, Docker Compose, Nginx
- **Design**: Figma (dark mode, cyan-blue accent, Inter + JetBrains Mono)

## Methodology

- Requirements and wireframes in 'docs/'
- Simplified Git flow ('main' / 'develop' / 'feature/*')
- Conventional Commits
- Task tracking with GitHub Projects

## Status

- Phase 1 complete - Django Ninja API with PostgreSQL, tested.
- Phase 2 in progress - React frontend.
